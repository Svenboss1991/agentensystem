Datenschutz

«Agentensystem» ist ein privates Werkzeug von Sven Bosshard und wird ausschliesslich von ihm selbst genutzt. Es gibt keine weiteren Nutzerinnen oder Nutzer.

Die Anwendung liest mit Svens Zustimmung seine eigenen Postfächer (Gmail, Outlook.com und weitere), um Mails einzuordnen, Antwortentwürfe vorzubereiten und offene Angelegenheiten nachzuverfolgen. Die Daten werden in einer geschützten Datenbank (Supabase) gespeichert, auf die nur Sven Zugriff hat. Zur Einordnung von Mails wird die Claude API von Anthropic verwendet.

Daten werden nicht verkauft, nicht für Werbung genutzt und nicht an Dritte weitergegeben.

Der Zugriff kann jederzeit in den Konto-Einstellungen von Google bzw. Microsoft widerrufen werden.
